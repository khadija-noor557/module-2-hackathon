# ♧ RecipeShare

**Good Food. Good Mood.**

RecipeShare is a recipe sharing web app for people who love food. Discover recipes, create your own, and share them with a community of food lovers.

## ✨ Features

- 🔐 Sign up, login and logout with Supabase Auth
- 🏠 Personal dashboard that greets you by name
- 🍲 Add recipes with photos and a live image preview
- ✏️ Edit and delete your own recipes
- 🗂️ Browse by category: Pakistani, Italian, Chinese, Desserts, Fast Food, Healthy
- 📱 Fully responsive, with a slide-in menu on mobile

## 🛠️ Built With

HTML · CSS · JavaScript · Bootstrap 5 · Supabase (Auth, Database, Storage) · SweetAlert2

## 🚀 Run Locally

1. Clone the repo:
   ```bash
      git clone https://github.com/khadija-noor557/module-2-hackathon.git
   ```
2. Create a free [Supabase](https://supabase.com) project with a `recipe_data` table and a public `images` storage bucket, and turn on Row Level Security.
3. Add your Supabase URL and publishable key to the JS files.
4. Open the folder in VS Code and run `index.html` with Live Server.
